Day 0

Start with the question, not the syntax.

Today's skill is simple: identify the table you need, choose the columns you want, filter the right rows, and sort the result.

Learn

Think in tables

A table is a collection of rows. A row is one record. A column is one attribute. SQL asks the database to produce a result set from those rows.

Learn

Four building blocks

SELECT name
FROM customers
WHERE country = 'India'
ORDER BY name;
Why it works

Read it like a sentence.

  • FROM — start with this table.
  • WHERE — keep only matching rows.
  • SELECT — return these columns.
  • ORDER BY — choose the output order.
Worked example

Find the largest orders.

SELECT order_id, amount
FROM orders
ORDER BY amount DESC
LIMIT 3;

First understand the question. Then identify the columns. Then write the smallest query that answers it.

Recall before practice

Without looking at the example: How would you find the names of customers from India, sorted alphabetically?

SELECT name FROM customers WHERE country = 'India' ORDER BY name;

Now go to Practice and write it yourself without copying.
