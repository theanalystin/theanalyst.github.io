# Sample data

performance_kpis.csv contains four fictional KPI rows for the Business Performance Intelligence case study. Values are synthetic, manually specified for teaching and do not represent a company, employer or client. The CSV fields are kpi_name, target_value, actual_value, unit and favourable_direction.

The dataset is intentionally small. It supports variance calculations but does not contain the segment-level or transaction-level data needed to test causes or validate an operational claim.
