Tabular Lab

A lightweight space to save, find, tag, and reuse SQL queries and analysis notes. Your workspace is stored in this browser; export a backup to move it elsewhere.

Prototype scope: This version manages saved SQL text locally. It does not connect to a database or execute queries. Avoid storing confidential data in query text or exported backups.
